# Welcome to Hypedrive Brand UI

This Storybook contains all the UI components used in the Hypedrive Brand Dashboard.

## Component Categories

### Primitives
Low-level building blocks that compose into higher-level components:
- **Button** - Various button styles (primary, neutral, error, basic, ghost)
- **Avatar** - User avatars with status indicators and groups

### Forms
Form controls and inputs for user interaction:
- **Input** - Text inputs with icons, affixes, password, search, and number variants
- **Select** - Dropdown select with groups and separators
- **Checkbox** - Checkboxes with labels and groups

### Data Display
Components for displaying data:
- **Badge** - Status badges with colors and variants
- **Card** - Content containers with headers and footers

### Layout
Structural and overlay components:
- **Modal** - Dialog modals with various sizes
- **Tooltip** - Hover tooltips for additional information

### Dashboard
Dashboard-specific components:
- **StatCard** - Statistics cards with icons and actions
- **WalletCard** - Wallet balance display

## Quick Start

```bash
# Run Storybook
pnpm storybook

# Build static Storybook
pnpm build-storybook
```

## Theme Support

Components support both light and dark themes. Use the theme toggle in the toolbar to switch between themes.

## Design System

This component library is built on:
- **Tailwind CSS v4** - Utility-first CSS
- **Radix UI** - Accessible primitives
- **AlignUI** - Design tokens and patterns
- **Phosphor Icons** - Consistent iconography
